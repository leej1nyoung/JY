## 지금 바로 (3단계 지인 테스트 전)

### ☐ 1. 편지 문장 직접 읽어 보기 [필수]
- 편지 문장은 제가 썼고 자동 검사(금지어, 어려운 용어, 9,600가지 조합 문장 완성)도 통과했어요. 하지만 **사람이 읽었을 때 따뜻하고 자연스러운지**는 직접 보셔야 해요.
- 어디를 보면 되나요: `packages/letter/src/templates.ts`. 각 문장이 한글로 정리돼 있어요.
- 어색한 문장은 표시해서 알려 주시면 고칠게요.

### ☐ 2. 국내 만세력 2곳과 대조 [필수, 출시 전까지]
- CLAUDE.md에 원래 있던 요구예요. 시중 만세력 앱이나 사이트 **2곳**에 아래 값을 넣고 결과가 같은지 확인해 주세요.
- 만세력 설정은 **"경도(지역) 보정 사용", "야자시 사용"**으로 맞추세요.

| 입력 | 기대 결과 |
|---|---|
| 1996-02-23 09:00 안동 (양력) | 丙子년 庚寅월 庚寅일 庚辰시 |
| 2000-01-01 23:50 서울 | 戊午일 甲子시 |
| 2000-01-02 00:10 서울 | 戊午일 甲子시 (경도 보정하면 전날 밤 11시대) |
| 1996-02-04 22:00 안동 | 乙亥년 己丑월 (입춘 22:08 직전) |
| 1996-02-04 22:30 안동 | 丙子년 庚寅월 (입춘 직후) |
| 1987-07-01 12:00 서울 | 시주 지지 巳 (서머타임 적용) |
| 1960-01-01 12:00 서울 | 시주 지지 午 (당시 표준시 UTC+8:30) |
| 음력 2017년 윤5월 1일 | 양력 2017-06-24 |

- 결과가 다르면 어느 만세력의 어떤 값인지 알려 주세요. 기준 차이인지 오류인지 제가 확인할게요.

### ☐ 3. 지인 테스트 인원 모으기 [권장]
- 5~20명 정도. MBTI가 다양할수록 좋아요.
- 3단계에서 "첫 장을 끝까지 읽었나", "결제 버튼을 눌렀나"를 측정해요. 결제 버튼을 눌러도 실제 결제는 되지 않고 "곧 열려요" 안내만 떠요.

### ☐ 4. 배포 계정 만들기 (Vercel) [필수, 3단계 전] [전달]
- https://vercel.com 에서 GitHub 계정으로 가입하고, `leej1nyoung/JY` 저장소를 연결하면 테스트용 주소가 생겨요.
- 연결할 때 설정값:
  - Root Directory: `apps/web`
  - Framework: Next.js (자동 인식)
- 무료 플랜(Hobby)은 **개인·비상업 용도**로 제한돼 있어요. 결제 없는 지인 테스트까지는 괜찮지만, **유료 판매를 시작할 때는 Pro 플랜(유료)으로 바꿔야** 해요. 요금은 가입 시점에 Vercel 요금 페이지에서 확인하세요.
- 막히면 화면을 캡처해서 보여 주세요. 같이 할게요.

### ☐ 4-1. 측정용 DB 만들기 (Supabase) [필수, 3단계 전]
- 지인 테스트에서 "몇 명이 끝까지 읽고 결제 버튼을 눌렀나"를 기록할 곳이에요. 무료 플랜으로 충분해요.
- 순서는 `docs/measurement.md`의 "설정 순서"에 그대로 적어 뒀어요. 요약하면:
  1. Supabase 가입 → 프로젝트 생성 (리전: 서울)
  2. SQL Editor에 `db/migrations/001_events.sql` 붙여 넣고 실행
  3. URL과 secret 키를 Vercel 환경변수에 넣기 (+ `STATS_KEY`에 긴 비밀 문자열)
- secret 키는 채팅으로 보내지 말고 Vercel에 직접 넣어 주세요.
- 결과는 `배포주소/stats?key=비밀문자열` 에서 봐요.

## 4단계(결제 + AI 두 번째 장) 전

### ☐ 5. 사업자 등록 [필수] [전달]
- 국세청 홈택스(hometax.go.kr) → 사업자등록 신청(개인).
- 업종은 온라인으로 콘텐츠를 파는 형태(전자상거래)예요. 정확한 업종코드는 홈택스 업종코드 조회나 세무서 상담으로 정하세요.

### ☐ 6. 통신판매업 신고 [필수] [전달]
- 정부24 또는 관할 시·군·구청에서 신고해요.
- PG사(결제대행사)에서 발급하는 "구매안전서비스 이용확인증"을 함께 내는 경우가 많으니, 7번 PG 가입과 같이 진행하세요.

### ☐ 7. 결제대행(PG) 가입 — 예: 토스페이먼츠 [필수]
- 운세·사주 관련 서비스는 PG사 심사에서 업종 제한이 있을 수 있어요. **가입 전에 고객센터에 "사주 기반 디지털 편지 콘텐츠, 건당 990원·2,990원, 선물용 2,990원, 간편결제 포함" 판매가 가능한지 먼저 문의**하세요.
- 승인되면 **테스트 키**만 저에게 알려 주시면 돼요. 실제 키는 배포 환경변수에 직접 넣으시는 게 안전해요.

### ☐ 8. 사이트 하단 사업자 정보 [필수] [전달]
- 상호, 대표자, 주소, 연락처, 사업자등록번호, 통신판매업 신고번호. 5·6번이 끝나면 알려 주세요. 지금은 자리만 잡아 뒀어요.

### ☐ 9. 이용약관 · 개인정보처리방침 [필수]
- CLAUDE.md 6번(보관 기간, 파기)과 7번 내용이 반드시 들어가야 해요.
- 초안은 제가 쓸 수 있지만, **최종본은 법률 전문가 검토를 권장**해요. 특히 아래 세 가지는 꼭 물어보세요.
  - "열람 후 환불 제한" 고지가 전자상거래법상 디지털 콘텐츠 청약철회 제한 요건을 충족하는지 (첫 장 무료 공개가 '맛보기 제공'으로 인정되는지)
  - 미성년자(만 14~18세) 결제 취소 처리 방식
  - 생일 알림 메일이 광고성 정보에 해당하는지

### ☐ 10. Anthropic API 키 [필수]
- https://console.anthropic.com 에서 가입하고, 결제수단과 **월 사용 한도**를 설정한 뒤 키를 발급하세요.
- 키는 저에게 채팅으로 보내지 말고, Vercel 환경변수에 직접 넣어 주세요. 이름은 그때 알려 드릴게요.

### ☐ 11. "MBTI" 표현 사용 확인 [권장]
- MBTI는 미국 The Myers & Briggs Foundation의 등록상표예요. 서비스명에는 쓰지 않지만 화면과 홍보 문구에 쓰고 있어요.
- 상표 사용 방식(예: "MBTI®" 표기, 공식 검사가 아니라는 고지)을 9번 법률 검토 때 함께 물어보세요.
