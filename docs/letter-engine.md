# 첫해 첫 장 (2단계) — 구현 기준

`packages/letter` 와 `apps/web` 의 동작 기준이다. CLAUDE.md 2, 3, 5-2 를 구현하면서 문서에 없던 세부를 여기서 정했다.

## 주기 규칙 (CLAUDE.md 3)

| 항목 | 기준 |
|---|---|
| 오늘 | 서버 시각을 한국 날짜로 바꾼 값 |
| 다음 생일 | 오늘보다 뒤인 첫 생일. 그 생일이 오늘 + 3개월보다 앞이면(3개월 미만) 그다음 생일 |
| 3개월 | 달력 기준 3개월. 말일을 넘으면 그달 말일 (11-30 + 3개월 = 2-28) |
| 생일 당일 방문 | 다음 해 생일 |
| 2월 29일생 | 평년에는 2월 28일 |
| 음력 생일 | 출생일의 음력 월·일로 매년 계산. **윤달생은 평달 같은 날**, 그달이 29일까지면 **30일생은 29일**로 챙긴다 (국내 일반 관행) |
| 만 14세 확인 | 체크박스 + 생년월일로 만 나이를 계산해 14세 미만이면 막는다. 2월 29일생은 평년 3월 1일에 나이가 든다 |

## 편지 조립 (CLAUDE.md 5-2)

**문체**: 1년을 지나온 미래의 나가 **기억하는 말투**로 쓴다 ("~했어", "~였지", "~던 것 같아"). "~했을 거야" 같은 짐작하는 말투는 쓰지 않는다 (테스트로 막음). 가끔 '우리'를 쓴다. 누구에게나 있을 법한 작은 장면은 쓰되 사생활을 지어내 단정하지 않는다.

1. **인사**: "○○아/야, 생일 축하해. 다음 생일의 나야." 이름이 없으면 "생일 축하해. 다음 생일의 나야." 받침에 따라 아/야, 한글이 아닌 이름은 조사 없이 그대로.
2. **비유 문단**: 여는 말(3종) + 일간 × 세운 기운 비유(50종, 짧은 명사구) + 비유를 풀어 주는 한 문장.
   - 명리 용어는 쓰지 않고 비유 한 번으로만 드러낸다 (예: 庚 일간 관성 해 = "쇠를 불에 달궈 두드리던 해").
3. **상황 문단**: 세운 천간 십신별 상황(10종 × 2, 정/편 톤) + 지지 그룹이 다르면 보조 한 줄(5종 × 2).
4. **MBTI 문단**: 세운 기운 5종 × 두 축의 글자 조합 4가지 = 20가지, 각 2버전. 문단 하나에 두 축과 조합 규칙(둘 다 버거움 → 마지막에 "그래도" / 하나씩 → 버거운 쪽 먼저, "그래도 … 너라서 잘 해냈어" / 둘 다 편함 → "잘 맞는 해" + 방심했던 순간)이 다 들어 있다. 문장 단위로 이어 붙이지 않아서 흐름이 끊기지 않는다.
5. **끊기 조각**: 첫해 기본형 그대로.

조각 선택은 "양력 출생일 | 입력 시각 | 출생지 | MBTI" 의 해시로 고정한다. 같은 사람은 몇 번을 열어도 같은 편지를 받는다. 이름은 키에 넣지 않는다.

### 자동 점검 (test/letter.test.ts)
- 일간 10 × 세운 60갑자 × MBTI 16 = 9,600개 조합 모두에서 문장이 완성된다.
- 금지어(투자·이직·퇴사·연애·결혼·이별·건강·병원·수술·죽·사고·반드시·무조건)와 명리 용어(비견~정인, 일간, 세운, 사주, 오행, 십신)가 편지 본문에 없다.

## 화면 (apps/web)

| 화면 | 내용 |
|---|---|
| `/` 메인 | 로고, 메인 문구, 가격("첫 장 무료 · 편지 전체 열람 990원"), 3단계 안내 |
| `/write` 입력 | 이름(선택), 생년월일(양력/음력·윤달), 시간(또는 모름), 출생지(시·도 → 시·군·구, 해외는 "준비 중"), MBTI, 생일 기준, 확인 2개 |
| `/preview` 미리보기 | 문장 검토용. 일간 10종 × 그해 테마의 MBTI 4조합 = 40통. **정식 런칭 전에 지운다** |
| `/letter` 편지 | 첫 장(끊긴 문장에서 멈춤) + 봉투 속 두 번째 장 연출 + "선물 상자 열어보기 · 990원" + 환불 제한 고지 |

- **저장하지 않는다.** 입력은 서버에서 계산에만 쓰고 버린다. 결과 편지는 그 브라우저 탭(sessionStorage)에만 둔다. 같은 입력이면 같은 편지가 다시 나온다.
- 결제 버튼은 아직 결제하지 않고 "곧 열 수 있어요" 안내만 띄운다 (실제 결제는 4단계).
- 밤 11시~자정 출생자에게만 "기준에 따라 해석이 다를 수 있어요" 안내.
- 검색 노출 차단(noindex)을 걸어 두었다. 정식 런칭 때 `apps/web/app/layout.tsx` 에서 제거한다.
- 푸터의 사업자 정보는 자리만 잡아 두었다 (`apps/web/components/Footer.tsx`).
