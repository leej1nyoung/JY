# 첫해 첫 장 (2단계) — 구현 기준

`packages/letter` 와 `apps/web` 의 동작 기준이다. CLAUDE.md 2, 3, 5-2 를 구현하면서 문서에 없던 세부를 여기서 정했다.

## 주기 규칙 (CLAUDE.md 3)

| 항목 | 기준 |
|---|---|
| 오늘 | 서버 시각을 한국 날짜로 바꾼 값 |
| 다음 생일 | 오늘보다 뒤인 첫 생일. 그 생일이 오늘 + 3개월보다 앞이면(3개월 미만) 그다음 생일 |
| 3개월 | 달력 기준 3개월. 말일을 넘으면 그달 말일 (11-30 + 3개월 = 2-28) |
| 생일 당일 방문 | 다음 해 생일 |
| 2월 29일생 | 평년에는 2월 28일 |
| 음력 생일 | 출생일의 음력 월·일로 매년 계산. **윤달생은 평달 같은 날**, 그달이 29일까지면 **30일생은 29일**로 챙긴다 (국내 일반 관행) |
| 만 14세 확인 | 체크박스 + 생년월일로 만 나이를 계산해 14세 미만이면 막는다. 2월 29일생은 평년 3월 1일에 나이가 든다 |

## 편지 조립 (CLAUDE.md 5-2) — 템플릿 3.0

배경: 한 통만 보면 사람 같아도, 여러 사람의 편지를 나란히 놓으면 같은 뼈대에 빈칸만 채운 게 드러났다 (지인 리뷰). 친구끼리 캡처해 비교하는 서비스라 가장 큰 위험으로 보고 구조를 바꿨다.

| 조각 | 내용 |
|---|---|
| 인사 | "○○아/야, 생일 축하해. 다음 생일의 나야." (이름 없으면 이름 없이) |
| 첫마디 | 10종. 편지를 여는 날짜·요일·시간대(새벽/아침/오후/저녁/밤, 한국 시각) + 그 달의 지금 공기(달마다 4종) + 다음 생일까지 길이(석 달~아홉 달, 열 달 이상은 1년). 인사 바로 다음 문단 |
| 본문 | `BODIES[세운 천간 십신][두 축 글자][버전]` 120통. 버전 v0 상황부터+비유, v1 감정부터+장면 한 줄, 끝에 계절 딴소리("아, 그리고…" 추신처럼), v2 계절부터. 조합 규칙(둘 다 버거움/하나씩/둘 다 편함)은 본문 안에 들어 있다 |
| 비유 칸 `{m}` | 일간 × 세운 기운 비유 50종 + 전하는 말투 5종 |
| 계절 칸 `{season}` | 기간 안에 15일 이상 들어 있는 양력 달 중 시점·편지를 여는 달과 다른 달 × 3종 |
| 보조 칸 `{sub}` | 세운 지지 그룹이 주 테마와 다를 때, 그룹별 4종 |
| 끊기 | 8종. `{when}` = 시점 부사구 |
| 시점 | 일지와 충하는 월운 달("마음이 제일 흔들렸던" 등 8종) → 합하는 달("마음이 좀 놓였던" 등 6종) → 입춘 무렵 → "어느 평범한 날에" |

- 시점 분포 실측 (2026-10-05, 1980~2005년생 624명): 가장 많은 단일 시점이 8%. 같은 규칙을 세운 천간 기준으로 했을 때는 54%가 6월로 몰렸다.
- 기억하는 말투. "~했을 거야" 금지. 가끔 '우리'.
- 본문·끊기의 "1년"은 기간이 열 달 미만이면 실제 길이로 바꾼다 ("넉 달 내내"). 년·달 모두 받침이 있어 조사가 같다.
- 금지 상투어(테스트): 너라서, 많이 애썼, 단단해졌, 나는 기억해, 그 시간을 지나와서, 잘 맞는 해였, 마음 한쪽, 숨 돌릴 틈, 차곡차곡, 한 걸음씩, 오롯이, 선물 같, 쉼표.
- 명사형·관형형으로 끝나는 감성 조각 문장("헷갈리는.") 금지.
- MBTI는 버거운 쪽 = 평소엔 안 하던 행동("쓰지도 않던 계획표"), 편한 쪽 = 그 성향이 드러나는 장면. 성향을 설명하지 않는다.
- 장면은 누구에게나 있는 것에서만. 직업·학업·가족을 짐작하는 말은 금지(테스트 `LIFE_ASSUMPTIONS`): 회의, 회사, 출근, 퇴근, 발표, 메일, 마감, 학교, 시험, 과제, 엄마, 아빠, 애인 등.
- 반복 검사: 9,600통에서 10글자 구절이 15% 넘게 나오면 실패 (끊기 8종은 각각 약 12.5%).

## 화면 (apps/web)

| 화면 | 내용 |
|---|---|
| `/` 메인 | 로고, 메인 문구, 가격("첫 장 무료 · 편지 전체 열람 990원"), 3단계 안내 |
| `/write` 입력 | 이름(선택), 생년월일(양력/음력·윤달), 시간(또는 모름), 출생지(시·도 → 시·군·구, 해외는 "준비 중"), MBTI, 생일 기준, 확인 2개 |
| `/preview` 미리보기 | 문장 검토용. 일간 10종 × 그해 테마의 MBTI 4조합 = 40통. **정식 런칭 전에 지운다** |
| `/letter` 편지 | 소인(일주·생년월일) + 첫 장(끊긴 문장에서 멈춤) + 봉투: 두 번째 장 목차 3줄과 흐린 첫 줄 + "선물 상자 열어보기 · 990원" + 환불 제한 고지. 흐린 부분은 실제 내용이 아닌 자리 안내 문장 |

- **저장하지 않는다.** 입력은 서버에서 계산에만 쓰고 버린다. 결과 편지는 그 브라우저 탭(sessionStorage)에만 둔다. 같은 입력이면 같은 편지가 다시 나온다.
- 결제 버튼은 아직 결제하지 않고 "곧 열 수 있어요" 안내만 띄운다 (실제 결제는 4단계).
- 밤 11시~자정 출생자에게만 "기준에 따라 해석이 다를 수 있어요" 안내.
- 검색 노출 차단(noindex)을 걸어 두었다. 정식 런칭 때 `apps/web/app/layout.tsx` 에서 제거한다.
- 푸터의 사업자 정보는 자리만 잡아 두었다 (`apps/web/components/Footer.tsx`).
