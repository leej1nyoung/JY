AM영업팀 브레인 팀 메일 사례 검색

메일함 기간 ~
예시: 러시아 오일 전략물자 판정통화대체 결제 처리Chestny Znak 라벨장기재고 특가 STO텐더 서류 원산지증명
질문을 입력하면 팀원들 메일에서 비슷한 사례를 찾아 드려요.
찾은 사례는 "누구 메일함에 있었는지"도 같이 보여 주니, 그분께 바로 물어보면 됩니다.

새 노하우 카드

노하우 카드는 메일에서 찾은 사례를 사람이 짧게 정리해 두는 곳이에요. 검색할 때 메일보다 먼저 보여 주기 때문에, 한 번 정리해 두면 다음 사람이 메일 스레드를 다 읽지 않아도 됩니다. 사례 상세 화면의 "노하우 카드로 정리" 버튼으로 시작하면 메일 스레드와 연결돼요.

PST 올리기

PST / OST / JSONL 파일을 여기로 끌어다 놓거나 눌러서 고르세요
  • 지운 편지함·정크·임시보관함·일정·연락처는 자동으로 빠집니다.
  • 여러 사람 메일함에 같은 메일이 있으면 한 통으로 합치고 "누구 메일함에 있었는지"만 기록합니다.
  • 올린 PST 원본은 적재가 끝나면 서버에서 지워집니다.
  • 개인 메일이 검색에 보이면 사례 상세에서 검색에서 빼기를 누르세요.
  • PST가 수 GB면 업로드보다 서버 PC에서 ingest.bat로 넣는 게 빠릅니다.
