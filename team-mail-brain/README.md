# AM영업팀 브레인 (team-mail-brain)

팀원들의 Outlook 메일(PST)을 한곳에 모아 **"이렇게 팔려고 하는데 유사사례 있어?"** 하고 물으면
비슷한 사례 메일 스레드를 찾아 주는 사내용 도구입니다.

- 찾은 사례마다 **누구 메일함에 있었는지**를 같이 보여 줍니다. 원본을 보고 그 사람에게 바로 물어보면 됩니다.
- 자주 쓰는 절차는 **노하우 카드**로 정리해 둡니다. 카드는 검색할 때 메일보다 먼저 나옵니다.
- **모든 데이터는 이 프로그램을 실행한 PC 안에만** 저장됩니다. 외부 서버로 아무것도 보내지 않습니다.

---

## 1. 보안 구조 (정보보안팀 설명용)

| 항목 | 내용 |
|---|---|
| 실행 위치 | 사내 PC 1대 (서버 역할). 팀원은 사내망에서 브라우저로 접속 |
| 저장 | `data/brain.db` 파일 하나 (SQLite). 외부 DB·클라우드 없음 |
| 외부 통신 | **없음.** 인터넷 연결이 없어도 동작함 |
| 저장 내용 | 메일 제목, 본문, 보낸/받은 사람, 날짜, 폴더, **첨부파일 이름** (첨부 내용은 저장하지 않음) |
| 원본 PST | 웹으로 올린 PST는 적재 후 자동 삭제 (`--keep-uploads`로 끄기 가능) |
| 접속 제한 | 서버 시작 시 정한 암호로만 접속 (HTTP Basic 인증) |
| AI 요약 (선택) | 기본값 **꺼짐**. 켜더라도 사내망/로컬 주소(사설 IP)의 LLM에만 연결하고, 외부 주소면 코드에서 거부 |
| 필요한 프로그램 | Python 3.10 이상 + `libpff-python`(PST 읽기 오픈소스, LGPL). 설치 파일이 `wheels/` 폴더에 들어 있어 인터넷 없이 설치됨 |

> 여러 사람의 메일을 모으는 일이므로 **시작 전에 팀장 승인과 정보보안 담당 부서 확인**을 받으세요.
> 팀원 각자가 올릴 메일 범위(기간·폴더)를 정하고, 개인 메일은 빼고 올리게 합니다.

---

## 2. 설치 (서버 역할 PC 1대에서만)

1. 이 폴더(`team-mail-brain`) 전체를 회사 PC에 복사합니다. (예: `D:\team-mail-brain`)
2. Python이 없으면 사내 소프트웨어 센터나 python.org에서 **Python 3.10 이상**을 설치합니다.
   (설치할 때 "Add python.exe to PATH" 체크)
3. `install.bat` 을 더블클릭합니다. PST 읽기 라이브러리가 `wheels` 폴더에서 설치됩니다.

## 3. 서버 켜기

`start_server.bat` 을 더블클릭 → 접속 암호를 정하면 이 PC의 사내 IP가 표시됩니다.

- 팀원 접속 주소: `http://<표시된 IP>:8765` (예: `http://10.20.30.40:8765`)
- 이 창을 닫으면 서버가 꺼집니다. 쓰는 동안 켜 두세요.
- 방화벽 허용 창이 뜨면 "개인/회사 네트워크" 허용. 접속이 안 되면 IT에 8765 포트 허용을 요청하세요.

## 4. 메일 넣기 (방법 3가지)

### 방법 A. 웹 화면에서 PST 올리기 (가장 쉬움)
1. 브레인 화면 → **메일 넣기** 탭
2. 메일함 주인 이름 입력 (예: 이진영), 기간(기본: 최근 1년)
3. PST 파일을 끌어다 놓기 → 적재 작업 표에서 진행 상황 확인

PST 만드는 법: Outlook → **파일 → 열기 및 내보내기 → 가져오기/내보내기 → 파일로 내보내기 → Outlook 데이터 파일(.pst)**
→ 받은 편지함·보낸 편지함 등 업무 폴더 선택 (하위 폴더 포함).

### 방법 B. PST 없이 Outlook에서 바로 내보내기 (Python 필요 없음)
팀원 본인 PC에서:
1. `scripts` 폴더를 받아서 Outlook을 켜 둔 채 `export_outlook.bat` 실행
2. 이름을 입력하면 바탕화면에 `이름_메일.jsonl` 파일이 생깁니다 (최근 1년, 지운편지함·정크 제외)
3. 이 파일을 웹 화면 **메일 넣기**에 올립니다

PST보다 파일이 훨씬 작고, Outlook에 연결된 보관(PST) 파일까지 한 번에 뽑힙니다.
특정 PST만: `powershell -ExecutionPolicy Bypass -File export_outlook.ps1 -Pst D:\메일\2025.pst -Out 이진영.jsonl`

> Outlook이 "다른 프로그램이 전자 메일 주소에 액세스하려고 합니다" 창을 띄우면 "허용"을 누르세요.
> PowerShell 실행이 막혀 있으면 방법 A를 쓰세요.

### 방법 C. 서버 PC에서 직접 (수 GB 대용량 PST)
`ingest.bat` 실행 → 이름, PST 경로(끌어다 놓기 가능), 기간 입력.
폴더를 지정하면 안의 PST를 모두 넣습니다.

```bat
python -m mailbrain ingest D:\pst\이진영 --owner 이진영 --since 2025-12-01
```

**같은 메일이 여러 사람 메일함에 있어도** 한 통으로 합치고 "누구 메일함에 있었는지"만 추가합니다.
같은 PST를 다시 넣어도 중복되지 않습니다.

## 5. 질문하기

문장으로 물어도 되고 단어만 넣어도 됩니다.

- `러시아에 오일 팔려고 하는데 전략물자 판정 받은 유사사례 있어?`
- `통화대체 결제 처리`, `Chestny Znak`, `31QE-10010`, `替代品号`

검색 방식
- 한글·한자는 두 글자씩 끊어 찾으므로 "전략물자"로 "전략물자관리원에"도 찾습니다.
- 품번은 `31QE-10010`, `31QE10010` 어느 쪽으로 써도 찾습니다.
- **동의어 묶음**이 있어 "러시아"로 찾으면 Russia, Россия도 같이 찾습니다 (`data/config.json`의 `synonyms`에서 팀 용어 추가).
- 질문 단어를 많이 담은 사례가 위로 옵니다. 빠진 단어는 빨간 칩으로 표시합니다.
- 결과 위에 **"이 주제를 많이 다룬 사람"** 이 나옵니다.

사례를 누르면 메일 스레드 전체가 날짜순으로 열립니다. 회신 메일은 새로 쓴 부분만 보여 주고, 인용된 이전 메일은 "원문 보기"로 접어 둡니다.

## 6. 노하우 카드 (자산화)

메일 스레드는 길고 흩어져 있어서, 처음 하는 사람은 다 읽기 어렵습니다.
사례 상세 화면의 **"노하우 카드로 정리"** 를 누르면 배경 / 진행 순서 / 관련 부서·담당자 / 필요 서류 / 주의할 점 틀이 채워진 카드가 열립니다.
한 번 정리해 두면 다음부터는 검색 맨 위에 카드가 나옵니다.

권장: 팀 회의 때 "이번 달 특이 건" 1~2개씩 카드로 정리.

## 7. 개인 메일·민감 정보 관리

- 자동 제외 폴더: 지운 편지함, 정크, 임시 보관함, 보낼 편지함, 일정, 연락처, 작업 등
- 자동 제외 제목: `[광고]`, 급여명세, 연말정산, 건강검진, 비밀번호 등 → `data/config.json`의 `exclude_subject_keywords`에서 추가
- 자동 제외 발신자: noreply 등 → `exclude_senders`
- 검색 결과에 개인 메일이 보이면: 사례 상세 → **검색에서 빼기**
- 한 사람의 메일을 통째로 빼기 (퇴사·요청 시):
  ```bat
  python -m mailbrain remove-owner 홍길동
  ```
  다른 사람 메일함에도 있던 메일은 그 사람 몫으로 남습니다.

`data/config.json`을 고친 뒤에는 서버를 껐다 켜세요. 제외 규칙은 **새로 넣는 메일부터** 적용됩니다.

## 8. (선택) 사내 AI로 요약 답변 받기

회사에 사내 LLM(사내 GPT 게이트웨이, 또는 서버 PC에 설치한 Ollama 등)이 있으면, 찾은 사례를 읽고
"어떤 절차로 했고 누구에게 물어보면 되는지"를 요약하게 할 수 있습니다. `data/config.json`:

```json
"llm": {
  "enabled": true,
  "kind": "openai",
  "url": "http://사내-LLM-주소/v1",
  "model": "모델이름",
  "api_key_env": "MAILBRAIN_LLM_KEY"
}
```

- `kind`: Ollama는 `"ollama"`, OpenAI 호환 사내 게이트웨이는 `"openai"`
- API 키가 필요하면 서버 PC의 환경변수 `MAILBRAIN_LLM_KEY`에 넣습니다 (파일에 쓰지 않음)
- **사설 IP(10.x, 172.16~31.x, 192.168.x)나 로컬 주소가 아니면 연결하지 않습니다.**
- AI 요약은 찾은 사례 6개 안에서만 답하게 되어 있지만, 틀릴 수 있으니 원문을 꼭 확인하세요.

## 9. 백업·이전

`data` 폴더 하나만 복사하면 됩니다 (`brain.db` + `config.json`).
다른 PC로 옮길 때도 프로그램 폴더 + `data` 폴더를 복사하면 그대로 동작합니다.

## 10. 알아 둘 한계

- 첨부파일은 **이름만** 검색됩니다 (내용은 읽지 않음. 사내 DRM 문서도 많아서).
- 메일 묶음(스레드)은 RE:/FW:/회신:/答复: 등을 뗀 **제목 기준**입니다. 제목을 바꿔 회신하면 다른 사례로 보입니다.
- 의미 검색("비슷한 뜻")이 아니라 **단어 검색**입니다. 안 나오면 다른 표현(영어·러시아어·약어)으로도 찾아보세요. 자주 쓰는 다른 표현은 `synonyms`에 넣어 두면 함께 찾습니다.
- 메일 수만 통 규모에서는 문제없이 동작하도록 만들었습니다 (SQLite 전문검색).

## 명령 모음

```bat
python -m mailbrain ingest <PST·폴더·jsonl...> --owner 이름 [--since YYYY-MM-DD | --all]
python -m mailbrain serve --host 0.0.0.0 --port 8765 --password 암호 [--keep-uploads]
python -m mailbrain search "질문" [--owner 이름]
python -m mailbrain stats
python -m mailbrain remove-owner 이름
```

데이터 폴더 위치를 바꾸려면 `--data D:\brain-data` 를 명령 앞에 붙이거나 환경변수 `MAILBRAIN_DATA`를 설정하세요.

## 개발자용

- 구조: `mailbrain/readers.py`(PST·EML·MSG·MBOX·JSONL 읽기) → `ingest.py`(정리·중복 합치기·색인) → `search.py`(사례 검색) → `server.py` + `static/index.html`(웹 화면). `llm.py`는 선택.
- 테스트: `python -m unittest discover -s tests`
- `.msg` 파일을 넣으려면 `pip install extract-msg` 추가 설치.
