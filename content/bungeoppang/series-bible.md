# 「붕어빵의 정체」 시리즈 설정집

> 포장마차에서 붕어빵을 굽는 청년이 사실은 국내 1위 제과 재벌의 숨겨진 3세였다.
> 그가 사랑하는 마카롱의 엄마, 트러플 사모님은 그를 "팥이나 굽는 집안"이라 무시한다.

- 장르: 음식 K-막장 로맨틱 코미디
- 형식: 인스타 컷 만화 (4:5 캐러셀 10~13장) / 유튜브 쇼츠·릴스 1분 영상
- 영어 제목: *Who Is Bungeoppang?*
- 업로드: 주 1회

---

## 1. 세계관 규칙

모든 회차가 이 규칙을 지켜야 한다. 반전과 개그는 전부 여기서 나온다.

| # | 규칙 | 쓰는 법 |
|---|---|---|
| 1 | **몸은 사람, 머리는 음식.** 머리 음식이 그 사람의 정체성이다. | 처음 보는 사람도 머리만 보고 계급과 성격을 짐작한다 |
| 2 | **음식의 성질 = 그 사람의 약점.** 물, 열, 습기, 충격, 시간 같은 물리 규칙을 그대로 따른다. | 위기는 약점으로 만들고, 반격도 상대의 약점으로 한다 |
| 3 | **"속(소)"은 그 사람의 진짜 출신이자 속마음이다.** 겉으로는 보이지 않는다. 남의 속을 묻는 건 무례한 일이다. | 붕어빵의 슈크림 반전이 성립하는 근거. 겉모습으로 속을 단정하는 사람이 결국 망신당한다 |
| 4 | **계급**: 고급 디저트(트러플, 마카롱, 케이크)는 상류층, 길거리 음식(붕어빵, 호떡, 어묵, 떡볶이)은 서민이다. | 트러플이 붕어빵을 무시하는 이유. 이 편견이 매 화 뒤집힌다 |
| 5 | **약점은 회복된다.** 눅눅해진 붕어빵은 다시 구우면 바삭해지고, 녹은 초콜릿은 냉장고에서 굳는다. 다만 모양이 조금 바뀐다. | 다쳐도 다음 화에 돌아온다. 회복 장면 자체가 개그다 |
| 6 | **이 세계에서 "먹는다"는 금기다.** 서로를 먹거나 먹는 장면, 먹는다는 대사가 없다. | 잔인하거나 징그러운 느낌을 막는다 |
| 7 | **크게 다치거나 죽는 장면은 없다.** 금이 가고, 녹고, 눅눅해지는 정도까지만 그린다. | 막장이어도 가볍게 웃으며 볼 수 있게 |

### 금지 사항
- 실제 기업, 브랜드, 제품명과 로고 (예: 실제 제과·베이커리 브랜드, 실제 호텔)
- 실제 인물을 닮은 얼굴이나 이름
- 기존 애니·드라마 캐릭터나 장면을 그대로 재현하는 것
- 정치, 종교, 지역 비하

| 숨기는 이유 | 할아버지의 조건: "틀에서 나온 놈은 틀을 알아야 한다." 1년 동안 신분을 숨기고 길에서 붕어빵을 구워야 승계 자격이 생긴다. 현재 8개월째 |

| 말투 | 존댓말, 짧은 문장. "괜찮습니다." "넣어 두세요." 감정 단어를 거의 쓰지 않는다 |

## 4. 반복 장치

| 장치 | 내용 |
|---|---|
| 약점 개그 | 붕어빵이 젖으면 → 김 실장이 드라이어를 꺼낸다 ("바삭하게 모시겠습니다.") |
| | 트러플이 녹으면 → 비서가 부채질하거나 냉장고 문을 연다 |
| | 마카롱에 금이 가면 → 하트 반창고 |
| 반전 공식 | 누군가 겉모습으로 단정한다 → 속(소)이 드러나며 뒤집힌다 |
| 효과음 | 충격 "두둥", 물벼락 "촤악!", 눅눅 "눅…", 녹음 "주르륵", 바삭 회복 "파삭!" |
| 엔딩 | 매 화 마지막 장에 다음 화 예고 한 줄 + 쉬운 질문 하나 (예: "팥파? 슈크림파?") |
